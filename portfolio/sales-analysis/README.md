# Sales Analysis - Beginner Portfolio Project

Beginner-level practice project for learning sales analysis with Excel, SQL, Python/Pandas and Power BI.

## Dataset
25 practice sales records covering January to March 2026.

This is a learning dataset, not real company data.

## Basic results
- Total revenue: 80,270 EGP
- Total units: 247
- Orders: 25
- Average order value: 3,211 EGP
- Highest-revenue category: Electronics
- Highest-revenue product: Wireless Mouse

## What I practiced
- Loading and checking data
- Basic KPIs
- Grouping and aggregation
- Comparing categories, cities and products
- Simple SQL
- Basic Python/Pandas
- Preparing a Power BI dashboard
