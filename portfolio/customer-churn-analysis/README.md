# Customer Churn Analysis - Beginner Portfolio Project

Beginner-level practice project focused on customer retention and churn analysis using Python/Pandas, SQL, an interactive web dashboard, and a Power BI specification.

## Dataset
30 synthetic customer records covering January to March 2026.

This is a learning dataset, not real company data.

## Business question
Which customer segments show the highest observed churn risk?

## Validated results
- Customers: 30
- Revenue represented by the records: 316,230 EGP
- Churned customers: 10
- Overall churn rate: 33.33%
- Highest-risk plan: Basic (61.54% churn)
- Highest-risk city: Qalyubia (66.67% churn)
- Higher-churn channel: Mobile (46.67% vs 20.00% Web)

## Key interpretation
The Basic plan is the clearest retention risk in this practice dataset. Qalyubia also has a high observed churn rate. These are descriptive findings only; the dataset is too small and synthetic to support predictive claims.
