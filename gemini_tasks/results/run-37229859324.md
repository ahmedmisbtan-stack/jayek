### 2. Obvious Beginner-Level Inconsistencies

1. **Missing File Referenced in Documentation:** `README.md` lists `sales_analysis_beginner.xlsx` under its `## Files` list, but this spreadsheet file is not present in the repository.
2. **Unused Date Column & Missing Monthly Breakdown:** Both `POWER_BI_DESIGN.md` and `POWER_BI_GUIDE.md` specify a "Revenue by Month" visual, and `analysis.py` converts the `Date` column to datetime (`pd.to_datetime`), but neither `analysis.py` nor `analysis.sql` actually computes monthly aggregations.
3. **KPI Rounding Discrepancy:** `README.md` presents the Average Order Value as `3,211 EGP` (integer rounding), while `analysis.py` outputs `3210.8` (two decimal places), without an explicit note in the README explaining the rounding.
