### 2. Obvious Beginner-Level Inconsistencies

1. **Brittle Relative Path in `analysis.py`**:  
   `analysis.py` calls `pd.read_csv("sales_data.csv")`. If run from the repository root rather than inside `portfolio/sales-analysis/`, it fails immediately with `FileNotFoundError`.
2. **Missing SQL Schema & Query Inconsistencies**:  
   `analysis.sql` lacks `CREATE TABLE` / schema definition or CSV import statements. Additionally, the SQL product query returns all 10 products with no `LIMIT`, whereas `analysis.py` uses `.head()` (top 5) and the SVG mockup displays only the top 3.
3. **SVG Wireframe Uses Plain Text Instead of Charts**:  
   `sales_dashboard_reference.svg` serves as the dashboard preview, but it contains only text labels with no graphical chart elements (e.g., SVG bars or trend lines). Furthermore, "Revenue by Category" only notes *"Electronics - highest revenue"*, omitting Home and Office figures entirely.
4. **Missing Execution and Environment Instructions in `README.md`**:  
   The project README displays output numbers but provides no instructions on prerequisites (`pip install pandas`), how to execute the Python script, or which SQL engine to use.
