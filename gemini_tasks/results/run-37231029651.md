### 2. Obvious Beginner-Level Inconsistencies

1. **Fragile Relative Path in `analysis.py`**:
   `analysis.py` uses a hardcoded relative path `pd.read_csv("sales_data.csv")`. If executed from the repository root or any directory other than `portfolio/sales-analysis/`, the script fails with `FileNotFoundError`.
2. **Missing SQL Table Definition (DDL) and Product Limit Mismatch**:
   `analysis.sql` lacks `CREATE TABLE` statements or SQLite import commands. Additionally, the SQL query for products selects all 10 products without a `LIMIT`, whereas `analysis.py` uses `.head()` (top 5) and the SVG mockup shows only the top 3.
3. **SVG Mockup Is Plain Text Rather Than Data Visualizations**:
   `sales_dashboard_reference.svg` is presented as a dashboard preview, but consists entirely of plain SVG `<text>` elements without graphical chart elements (e.g., SVG bars or trend lines). Furthermore, under "Revenue by Category" it only notes *"Electronics - highest revenue"* while omitting Home and Office figures entirely.
4. **Lack of Run/Reproducibility Instructions in `README.md`**:
   The README lists files and outputs but contains no execution instructions or dependency requirements (e.g., `pip install pandas`, how to execute `analysis.py`, or which SQL engine to use).
