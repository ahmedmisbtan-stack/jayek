# JAYEK — GitHub upload package

This folder is prepared for the GitHub web uploader on a phone.

## Important
- Do **not** upload the ZIP itself to GitHub. Extract this folder first.
- Firebase `google-services.json` files are intentionally excluded from this package. They can be added later through GitHub Actions secrets when Android builds are enabled.
- The current source contains the API and Flutter application source, but the Android platform folders are not yet present. The APK workflow therefore stays gated until those folders are added.
