# بيّنات — Android

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose وMaterial 3، وليس WebView.

## مرجع المحتوى وتجربة الموقع

الموقع المرجعي المعتمد: https://www.bayynat.org.lb/

بنية المحتوى التي يجب تمثيلها داخل التطبيق تشمل:
- القرآن والتفسير والمسائل القرآنية.
- الفقه والرسائل العملية وكيفية تأدية العبادات.
- المكتبة والكتب والقرآنيات والحديث والأخلاق.
- حقيبة بيّنات: الأعمال والمستحبات، المناسبات، المواقيت، الدعاء، الصحيفة السجادية، الأدعية المشهورة، المناجيات، أدعية أيام الأسبوع والزيارات.
- أرشيف السيد: الخطب والبيانات والأخبار والسيرة والمقابلات.
- أخبار بيّنات والكتابات والمحاضرات والمقابلات.
- خدمات التطبيق المساندة: مواقيت الصلاة، التنبيهات والأذان، القبلة، الأذكار والسبحة، أسماء الله الحسنى، التقويم الهجري، الصوتيات والويدجت.

الموقع المرجعي بوابة محتوى مؤسسية؛ لذلك تُنقل هيكلية المحتوى والتصنيفات إلى واجهات Android أصلية مع الحفاظ على ألوان وشعار بيّنات، وليس نسخ HTML حرفيًا.

## المصادر والحقوق

- مواقيت الصلاة: خدمة بيّنات الرسمية تتيح اختيار اليوم/الأسبوع/الشهر/فترة محددة، الموقع عبر الجهاز أو الخريطة، اختيار البلد والمدينة، وتنزيل PDF وإمساكية رمضان. يجب إظهار طريقة الحساب ومصدر المواقيت وعدم الادعاء بمطابقة رسمية قبل التحقق من قواعد الحساب المعتمدة.
- الحساب المحلي للصلاة: مكتبة Adhan؛ طريقة الحساب والمذهب قابلة للاختيار، ولا تُفترض مدينة المستخدم.
- نص القرآن والتلاوات: AlQuran Cloud API، مع الإسناد إلى Quran Academy وTanzil وفق بيانات الخدمة. شروط AlQuran Cloud تسمح بالاستخدام غير التجاري للنص مع الحفاظ على الرسم والضبط وإسناد المصدر؛ يجب مراجعة الشروط قبل أي توزيع تجاري. التلاوات متاحة للبث/الاستخدام التعليمي غير التجاري بحسب ترخيص الخدمة، ويُحفظ اسم القارئ والمصدر.
- الأذكار والأدعية: يلزم إظهار المصدر والمرجع لكل نص، وعدم إنشاء نصوص منسوبة إلى الحديث دون تحقق.
- صوت الأذان: لا تُضمّن ملفات أذان مجهولة الحقوق؛ يمكن للمستخدم اختيار ملف من جهازه وتعيينه كنغمة لقناة إشعار الصلاة. التلاوات تُبث من AlQuran Cloud أو من ملفات يملك المستخدم حق استخدامها.

## متطلبات Android

- الموقع: طلب الإذن وقت الحاجة فقط، مع دعم الإدخال اليدوي عند الرفض.
- الإشعارات: طلب POST_NOTIFICATIONS على Android 13+، وقنوات مستقلة للأذان والتذكير.
- المنبهات الدقيقة: لا تُستخدم إلا إذا احتاجها المستخدم وسمح بها النظام؛ توفير بديل WorkManager عند عدم توفرها.
- الصوت: Media3 مع احترام وضع الصامت/عدم الإزعاج وسياسات foreground service.
- الويدجت: Android AppWidget/Glance للشاشة الرئيسية. عرض معلومات الصلاة على شاشة القفل يعتمد على إصدار Android والجهاز وسياسات الشركة المصنّعة؛ لا يمكن ضمان ويدجت Lock Screen موحد على كل الأجهزة.

## التحقق

كل دفعة تغيير تُبنى عبر GitHub Actions workflow Bayynat Android APK. نجاح assembleDebug لا يغني عن اختبار GPS والحساسات والإشعارات والصوت والويدجت على جهاز فعلي.

## حالة التنفيذ الحالية

تم تنفيذ الأساس التالي في الفرع:
- فهرس القرآن من 114 سورة عبر AlQuran Cloud، قراءة النص العثماني مع تخزين السور المفتوحة دون اتصال، البحث باسم السورة، واستعادة آخر سورة.
- بث تلاوات السور عبر Media3 مع اختيار سبعة قرّاء، وتشغيل ملفات صوتية يختارها المستخدم.
- حساب مواقيت محلي مع إذن الموقع أو إدخال الإحداثيات، واختيار طريقة الحساب؛ مع رابط مباشر لخدمة بيّنات الرسمية لأن الحساب المحلي ليس بديلًا معتمدًا عنها.
- تنبيه الصلاة القادم، قناة إشعار بصوت نظام أو ملف أذان يختاره المستخدم، إعادة جدولة الصلاة التالية، والاستعادة بعد الإقلاع وتغيير الوقت/المنطقة الزمنية.
- بوصلة القبلة مع تعويض الانحراف المغناطيسي وحساس بديل عند غياب Rotation Vector.
- سبحة بعدّادات محفوظة ومراجع للأذكار المحدودة المتاحة.
- التاريخ الهجري مع إزاحة يدوية.
- ويدجت Glance للشاشة الرئيسية، وتصنيف شاشة القفل للأجهزة التي تدعمه، وإشعارات/تحكم MediaSession على شاشة القفل.
- فهرس حقيبة بيّنات بروابط الأقسام الفرعية الرسمية، وروابط الفقه والمكتبة والأرشيف والأخبار والمحاضرات والمقابلات.

## ما لا يزال يحتاج اعتمادًا أو اختبارًا قبل وصف التطبيق بأنه مكتمل

- تثبيت ومراجعة خوارزمية مواقيت بيّنات نفسها؛ المكتبة المحلية الحالية تعرض طريقة حساب يختارها المستخدم ولا تدّعي التطابق مع المواقيت الرسمية التي تتضمن تفاصيل إضافية.
- إدخال كامل قائمة الأسماء ومعانيها من المادة الأصلية بعد مراجعة تحريرية؛ الشاشة الحالية تعرض أمثلة موثقة فقط.
- توسيع الأذكار إلى كامل أبواب الصباح والمساء والنوم وبعد الصلاة مع مراجعة المراجع.
- تحويل صفحات المكتبة والفقه والأرشيف من روابط متصفح إلى محتوى أصلي داخل التطبيق إذا توفرت واجهات بيانات/إذن إعادة استخدام.
- اختبار الأذان الفعلي، الموقع، الحساسات، الخلفية، الويدجت وشاشة القفل على أجهزة فعلية وإصدارات Android متعددة.

لا يُعد نجاح البناء وحده إثباتًا لصحة المواقيت أو عمل الحساسات والأذان على كل جهاز.
